# Security Policy

## Supported Versions

Security fixes are applied to the latest published `0.1.x` release on `main`.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately via [GitHub Security Advisories](https://github.com/GhabiX/spine-plugin/security/advisories/new) rather than opening a public issue. Include reproduction steps and affected package versions; we aim to acknowledge reports within 72 hours.
